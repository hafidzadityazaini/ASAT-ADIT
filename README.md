🚗 DRIVE-VERSE

Drive-Verse adalah aplikasi mobile marketplace mobil yang memungkinkan pengguna mencari, melihat, dan membeli kendaraan dengan mudah. Aplikasi menampilkan daftar mobil yang tersedia secara real-time lengkap dengan informasi seperti nama mobil, tahun produksi, warna, harga, status reservasi, dan fitur pembelian langsung.

📱 Tampilan Aplikasi

Aplikasi menggunakan desain modern bertema dark mode dengan tampilan kartu kendaraan yang informatif dan mudah digunakan.

Fitur Tampilan:
Header aplikasi dengan branding Drive-Verse
Daftar mobil yang tersedia secara live
Informasi kendaraan:
Nama mobil
Tahun produksi
Warna kendaraan
Harga
Status reservasi
Tombol pembelian langsung
✨ Fitur Utama
🔍 Pencarian Mobil

Menampilkan berbagai pilihan kendaraan yang tersedia di database secara real-time.

🚘 Detail Kendaraan

Setiap mobil memiliki informasi lengkap:

Nama kendaraan
Tahun produksi
Warna
Harga
🛒 Pembelian Mobil

Pengguna dapat membeli kendaraan melalui tombol Beli yang tersedia pada setiap kartu mobil.

📌 Status Reservasi

Mobil yang sudah dipesan akan diberi label "Direservasi" sehingga pengguna mengetahui ketersediaannya.

📡 Data Live

Daftar kendaraan diperbarui secara langsung dari sumber data sehingga informasi selalu terbaru.

🚀 Cara Menjalankan Project
1. Clone Repository
git clone https://github.com/username/drive-verse.git
2. Masuk ke Folder Project
cd drive-verse
3. Install Dependency
flutter pub get
4. Jalankan Aplikasi
flutter run
